# tree-sitter-viewer 

这是一个类似于 `Tree-sitter` 官网[`游乐场`](https://tree-sitter.github.io/tree-sitter/7-playground.html)的`VS Code`扩展插件。  
您可以使用该插件方便的查看不同开发语言的抽象语法树。  
以下是目前支持查看语法树的语言列表：  
- Bash
- C
- C++
- C#
- CSS
- Go
- Haskell
- HTML
- Java
- JavaScript
- JSON
- PHP
- Python
- Regex
- Ruby
- Rust
- Scala
- TypeScript
